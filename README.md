# Закупки — почтовый ассистент

Веб-приложение для отдела закупок: каталог товаров, поставщики, рассылка запросов КП через **Яндекс.Почту**, автоматический разбор ответов и сводная таблица с графиками.

Один пользователь, SQLite, подходит для локального ПК и деплоя на [Amvera](https://amvera.ru).

## Возможности

1. **Каталог** — категории и наименования товаров  
2. **Поставщики** — контакты + привязка ассортимента  
3. **Запрос КП** — выбор товаров и поставщиков → письма «как от человека» по шаблону  
4. **Ответы** — опрос IMAP, сопоставление по коду `[RFQ-…]` в теме  
5. **Сводка** — таблица цен/сроков и столбчатый график сравнения  

## Быстрый старт (локально)

```powershell
cd C:\Users\warch\Downloads\zakupki
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

В `.env` укажите:

```env
APP_PASSWORD=ваш_пароль
SECRET_KEY=длинная-случайная-строка
MAIL_USER=you@yandex.ru
MAIL_PASSWORD=пароль_приложения_яндекса
MAIL_FROM=you@yandex.ru
SENDER_NAME=Иван Иванов
SENDER_COMPANY=ООО Ромашка
```

Запуск:

```powershell
uvicorn app.main:app --host 127.0.0.1 --port 3000 --reload
```

Откройте http://127.0.0.1:3000

## Яндекс.Почта

1. Создайте [пароль приложения](https://id.yandex.ru/security/app-passwords)  
2. Включите IMAP в настройках почты (если ещё не включён)  
3. Хосты уже прописаны: `smtp.yandex.ru:465`, `imap.yandex.ru:993`  

Для тестовых ответов: ответьте на письмо запроса, **оставив код `[RFQ-…]` в теме**.

## AI-разбор (опционально)

Без ключа ответы разбираются эвристиками (цена/сроки рядом с названием товара).  
С `AI_API_KEY` (Gemini OpenAI-compatible) качество разбора выше.

## Amvera

Репозиторий уже содержит `Dockerfile` и `amvera.yml` (порт 3000, том `/data`).

1. Создайте приложение из этого репозитория (Docker)  
2. Задайте переменные окружения (как в `.env.example`), `DATA_DIR=/data`  
3. Подключите persistent volume на `/data`
