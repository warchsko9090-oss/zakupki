# Закупки — почтовый ассистент

Веб-приложение для отдела закупок: каталог товаров, поставщики, рассылка запросов КП через **Яндекс.Почту**, автоматический разбор ответов и сводная таблица с графиками.

Один пользователь, SQLite, подходит для локального ПК и деплоя на [Amvera](https://amvera.ru).

## Возможности

1. **Каталог** — категории и наименования товаров  
2. **Поставщики** — контакты + привязка ассортимента  
3. **Запрос КП** — выбор товаров и поставщиков → письма «как от человека» по шаблону  
4. **Ответы** — опрос IMAP, сопоставление по коду `[RFQ-…]` в теме  
5. **Сводка** — таблица цен/сроков и столбчатый график сравнения  

## Быстрый старт (Windows)

**Самый простой способ** — двойной клик по `start.bat`  
(или в cmd: `start.bat`).

Не вызывайте голый `uvicorn`: в cmd после `Activate.ps1` команда не попадает в PATH.  
Скрипт сам берёт `.venv\Scripts\uvicorn.exe`.

PowerShell:

```powershell
cd C:\Users\warch\Downloads\zakupki
.\start.ps1
```

Откройте http://127.0.0.1:3001

В `.env` укажите:

```env
APP_PASSWORD=ваш_пароль
SECRET_KEY=длинная-случайная-строка
MAIL_USER=you@yandex.ru
MAIL_PASSWORD=пароль_приложения_яндекса
MAIL_FROM=you@yandex.ru
SENDER_NAME=Иван Иванов
AI_API_KEY=ключ_из_Google_AI_Studio
```

## AI-ассистенты (бесплатный Gemini)

1. **Поиск поставщиков** (`/search`) — чатовый запрос → веб-поиск → разбор сайтов AI → отчёт (сайт, контакты, цена) → кнопка «Добавить в базу» с привязкой к номенклатуре.  
2. **Письма КП** — AI пишет черновик → вы правите на странице запроса → только потом «Отправить».

Ключ: [Google AI Studio](https://aistudio.google.com) → Get API key → `AI_API_KEY` в `.env`.

## Яндекс.Почта

1. Создайте [пароль приложения](https://id.yandex.ru/security/app-passwords)  
2. Включите IMAP в настройках почты (если ещё не включён)  
3. Хосты уже прописаны: `smtp.yandex.ru:465`, `imap.yandex.ru:993`  

Для тестовых ответов: ответьте на письмо запроса, **оставив код `[RFQ-…]` в теме**.

## AI-разбор (опционально)

Без ключа ответы разбираются эвристиками (цена/сроки рядом с названием товара).  
С `AI_API_KEY` (Gemini OpenAI-compatible) качество разбора выше.

## Amvera

Репозиторий уже содержит `Dockerfile` и `amvera.yml` (порт 3000, том `/data`).

1. Создайте приложение (Docker), подключите GitHub webhook на ветку `master`
2. Переменные окружения как в `.env.example`, обязательно `DATA_DIR=/data`
3. Том постоянного хранилища: `persistenceMount: /data` (уже в `amvera.yml`)

### Перенос локальной базы и файлов

Вложения (КП, счета) хранятся **не внутри SQLite**, а в папке `attachments` рядом с БД.

1. Один раз задеплойте приложение (чтобы появилась папка Data)
2. Остановите приложение
3. Amvera → **Репозиторий → Data** → загрузите:
   - `zakupki.db` (из локальной `data/zakupki.db`)
   - содержимое локальной `data/attachments/` в Data/`attachments/` (если папка есть)
4. Запустите приложение снова

Проверка: **Настройки → Хранилище данных** — путь должен быть `/data/...`.
